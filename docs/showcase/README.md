## 画廊使用指南

当 MathViz 生成出成功的 MP4 时，将最精彩的片段加入此画廊：
1. 有明确的教学亮点
2. 文字在 README 尺寸下可读
3. 色调稳定，无破损帧
4. 循环足够短，可快速浏览
5. 描述解释概念本身，而不仅仅是文件名
