## 1. 快速开始

### 首次启动

**macOS：**
```
双击 scripts/start-teacher-console.command
```
或终端执行：
```
./scripts/start-teacher-console.sh
```

**Windows：**
```
双击 scripts\start-teacher-console.bat
```

启动后脚本会自动：
1. 创建 Python 虚拟环境（仅首次）
2. 安装依赖
3. 启动本地服务器
4. 在浏览器自动打开控制台

### 浏览器访问

启动后访问：**http://127.0.0.1:7860**

## 3. 生成动画

### 第一步：配置模型（首次使用）

点击左下角 ⚙️ 按钮 → 选择厂商（如 DeepSeek）→ 填入 API Key → 点"保存配置"→ 点"测试连接"

> **如果没有 API Key，也可以使用"本地快速草稿"模式**（取消勾选"AI 深度生成"），但生成的画面较为简单，仅用于测试流程。

### 第二步：输入教学主题

在输入框写入你想讲解的内容。详见下一节"如何写好提示词"。

### 第三步：选择参数

| 参数 | 说明 |
|------|------|
| 学生阶段 | 初中 / 高中 / 大学本科 / 进阶学习者 |
| 时长 | 30 / 60 / 90 / 120 秒 |
| 风格 | 清爽课堂 / 电影感 / 黑板推导 / 极简几何 |
| AI 深度生成 | 勾选 = 调用 AI 模型生成精细内容；不勾选 = 本地快速草稿 |

### 第四步：生成

点击 **"生成动画方案"**。等待过程中可看到各阶段卡片的状态更新。

> ⏳ 生成过程中请勿点击阶段卡片，等待完成后卡片会恢复正常可点击状态。

生成完成后：
- 点阶段卡片可以查看对应内容（教学方案、分镜、Manim 代码等）
- 点击 **"渲染低清预览"** 生成视频
- 视频生成后可在预览区域播放

## 4. 如何写好提示词

这是**最关键**的一步——提示词的质量直接决定动画的准确度。

### 原则

**越具体越好。** 不要写笼统的概念名，要描述"先发生什么、再发生什么、最后显示什么"。

### 对比

```
❌ 太笼统：
"证明勾股定理"

✅ 够具体：
"用面积拼接法证明勾股定理 a² + b² = c²，适合初中生理解。

画面分四步：
1. 画一个直角三角形，直角在左下角，两条直角边分别标 a（底边）和 b（高），
   斜边标 c。直角处画直角符号。
2. 在三角形的三条边上分别向外画出三个正方形：a边上的正方形（蓝色，面积a²）、
   b边上的正方形（红色，面积b²）、c边上的正方形（绿色，面积c²）。
3. 用动画展示两个小正方形的面积之和等于大正方形的面积，
   通过图形分割和拼接来直观证明。
4. 最后在画面底部居中显示结论公式 a² + b² = c²。

风格：清爽课堂。深色背景，标签放在三角形顶点旁边稳定位置，不要重叠。"
```

### 好提示词的要素

| 要素 | 说明 | 示例 |
|------|------|------|
| **明确主题** | 一句话说清要讲什么 | "用面积拼接法证明勾股定理" |
| **分步描述** | 用数字列出画面顺序 | "画面分四步：1. 2. 3. 4." |
| **具体物体** | 说明每个阶段出现什么图形 | "画一个直角三角形"、"三个正方形" |
| **颜色和位置** | 物体颜色、标签位置 | "蓝色"、"底部居中"、"放在顶点旁边" |
| **动画动作** | 物体如何出现 | "画出"、"展示"、"显示" |
| **风格和约束** | 整体风格和不要做的事 | "清爽课堂"、"不要重叠" |

### 示例模板

```
[主题一句话概括]，适合[学生阶段]理解。

画面分[数字]步：
1. [第一步：画什么，标什么，放在哪]
2. [第二步：出现什么，颜色，位置]
3. [第三步：动画怎么做]
4. [第四步：最后显示什么]

风格：[风格描述]。额外要求。
```

## 5. 渲染视频

### 首次渲染

生成动画方案后，点击 **"渲染低清预览"**。首次渲染会下载 Manim 相关缓存，后续会更快。

### 渲染依赖检查

在设置面板 → 依赖检查 tab 中可查看哪些工具已安装。

| 工具 | 作用 | 缺少时的影响 |
|------|------|------------|
| manim | 核心渲染引擎 | ❌ 无法渲染 |
| ffmpeg | 视频编码 | ❌ 无法生成 MP4 |
| latex | 公式渲染（MathTex） | ⚠️ 公式用纯文本显示 |
| dvisvgm | LaTeX → SVG 转换 | ⚠️ 公式用纯文本显示 |

### 如果渲染失败

1. 检查设置面板 → 依赖检查是否所有必需工具都已安装
2. 尝试用非 AI 模式（取消勾选"AI 深度生成"）生成一个简单场景测试
3. 查看运行目录下的 `render_result.json` 获取详细错误信息
4. 如果持续失败，尝试更简单的提示词

### AI 深度生成失败时的自动处理

如果 AI 深度生成因为网络或服务端原因失败，系统会自动切换为本地快速草稿模式，并在页面顶部显示黄色提示。这种情况下生成的动画较为简单，但仍然可以正常渲染和播放。

### 生成过程中的注意事项

生成和渲染过程中，阶段卡片会自动进入忙碌状态，防止误操作。如果页面状态异常，刷新浏览器（F5 / Cmd+R）即可恢复。

## 6. 常见问题

### Q: 页面按钮点击无反应

刷新页面（Cmd+R）。如果仍不行，检查终端中 server 是否还在运行。

### Q: 渲染失败，提示 LaTeX 错误

你的电脑没装 `dvisvgm`，`Tex()` / `MathTex()` 调用会失败。两个解决办法：
- **推荐**：装 dvisvgm → `sudo tlmgr install dvisvgm`
- **临时**：AI 生成的代码会被自动降级为 `Text()`，画面能出来但公式显示为纯文本

### Q: 生成的动画和我想的不一样

提升提示词的详细程度（参考第 4 节）。越具体 → 越准确。

### Q: 视频画面空白或卡住

可能是 Manim 渲染超时。减少动画时长或简化画面步骤。

### Q: 如何切换模型

点击左下角 ⚙️ → 厂商下拉菜单选择提供商 → 填入对应 API Key → 保存 → 测试连接。

### Q: 当前支持哪些 AI 厂商

DeepSeek、Qwen（通义千问）、Kimi、GLM（智谱）、Doubao（豆包）、OpenAI 等所有兼容 OpenAI API 的厂商。

### Q: 生成的内容保存在哪里

每次生成都会在 `runs/` 目录下创建一个独立文件夹，包含所有中间产物（JSON、Python 代码、视频等）。
