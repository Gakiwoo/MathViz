# M2 教学动画控制台 · 使用说明

> 收到这个项目后，按以下步骤启动服务。

---

## 环境要求

- **Python 3.10 或更高版本**
  - Windows：从 https://www.python.org/downloads/windows/ 下载安装
  - macOS：从 https://www.python.org/downloads/ 下载安装
  - 安装时记得勾选 ✅ **Add Python to PATH**
- **网络连接**（首次启动需要下载依赖包）

---

## 启动服务

### Windows 用户

```
双击 scripts\start-teacher-console.bat
```

或打开 PowerShell 运行：

```powershell
.\scripts\start-teacher-console.ps1
```

### macOS 用户

```
双击 scripts/start-teacher-console.command
```

或终端运行：

```bash
./scripts/start-teacher-console.sh
```

---

## 启动流程

脚本会自动完成以下步骤：

```
[1/4] Setting up Python environment...    ← 创建虚拟环境（仅首次）
[2/4] Checking web dependencies...        ← 安装依赖包（仅首次）
[3/4] Checking render tools...            ← 检查并自动安装 ffmpeg
[4/4] Starting teacher console...         ← 启动网页服务
```

当看到以下输出时，说明启动成功：

```
  Teacher console: http://127.0.0.1:7860
  Press Ctrl+C to stop.
```

浏览器会自动打开。如果没自动打开，手动访问 **http://127.0.0.1:7860**。

## 首次使用：配置 AI 模型

首次打开控制台后，需要配置 AI 模型才能使用"AI 深度生成"模式：

1. 点击左下角 **⚙️ 设置** 按钮
2. 在"模型配置"中选择厂商（默认 DeepSeek）
3. 填入你的 **API Key**
4. 点击 **"保存配置"**，然后点击 **"测试连接"** 验证
5. 也可以在"依赖检查"中查看渲染工具是否齐全

> **没有 API Key 也能使用**：取消勾选"AI 深度生成"即可使用本地快速模式，适合测试流程，生成的画面较简单。

## 操作流程

### 生成动画

1. 输入教学主题（提示词）
2. 选择学生阶段、动画时长、风格
3. 勾选"AI 深度生成"使用 AI 模式，不勾选则使用本地快速模式
4. 点击 **"生成动画方案"**，等待各阶段处理完成
5. 生成完成后可点击阶段卡片查看教学内容、分镜、代码等

### 渲染视频

1. 生成完成后，点击阶段卡片的 **"待渲染"** 或预览区的 **"渲染低清预览"** 按钮
2. 等待 Manim 渲染完成
3. 渲染完成后可直接在页面播放视频

> ⚠️ **注意**：生成或渲染过程中请勿点击阶段卡片，等待当前操作完成后再操作。

## 常见问题

### Q: 启动后窗口闪退

双击 `.bat` 后窗口闪一下消失，说明有错误。改为在终端手动运行看报错：

```
.\scripts\start-teacher-console.ps1
```

常见原因：
- Python 没装或没加到 PATH
- 网络问题导致依赖包下载超时（重试或换网络）

### Q: 提示"Python 3.10+ is required"

说明电脑没装 Python，或者没加到 PATH。

- 安装 Python 后重启终端/双击 `.bat` 即可
- 如果已安装但仍报错，运行 `python --version` 检查版本

### Q: 第 3 步显示 "ffmpeg missing"

启动脚本会自动用 winget 安装 ffmpeg，等它装完即可。如果 winget 装不上会从官网下载。

### Q: 浏览器打开后页面空白/加载中

检查启动窗口是否还开着（关闭窗口 = 关闭服务）。如果窗口正常，刷新浏览器页面（F5 / Cmd+R）即可。

### Q: 启动后浏览器弹不出来

手动在浏览器地址栏输入：**http://127.0.0.1:7860**

### Q: 如何关闭服务

在启动窗口中按 **Ctrl+C** 即可停止。

### Q: 生成失败，提示"已自动切换为本地快速草稿"

说明 AI 深度生成因网络或服务端原因失败了，系统已自动回退到本地快速模式。生成的动画较为简单，但可以正常渲染和播放。

### Q: 第二次循环渲染慢或报错

每次生成新的动画方案后，请确保视频预览区显示"等待渲染"再点击渲染按钮。如果在生成过程中误点了阶段卡片，刷新页面（F5）恢复即可。

## 参数说明

| 参数 | 作用 | 示例 |
|------|------|------|
| `--port 端口号` | 修改端口（默认 7860） | `.\scripts\start-teacher-console.ps1 --port 8080` |
| `--no-open` | 不自动打开浏览器 | `.\scripts\start-teacher-console.ps1 --no-open` |
